### v1.0.1 + v2-gap exit state

- **M1 (parallel fanout):** live. Wall-clock gain on cold-cache physical stage validated by the 3-way barrier test; warm-cache path is unaffected.
- **M2 (OSI child-level fields):** live. Fluid contracts written from v1.0.1 forward carry per-entity glossary, vendor extensions, unique-key metadata, and display labels.
- **M3 (targeted repair):** live. Builder or transformation failures trigger one cache-bypassed re-run of the blamed stage; logical failures surface the report unchanged (v1.4+ will extend repair into logical).
- **B1 (semantic retrieval):** live. Every cache-miss LLM prompt for a new intent or DDL bundle is seeded with up to 3 prior similar forged models from `memory/semantic` — without any client code change.
- **B2 (embedding vector backend):** optional. `pip install data-product-forge[vector]` flips the ranking on; absence leaves v1.0 behaviour bit-identical.
