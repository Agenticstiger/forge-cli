Build an aggregated data product (ADP, Silver layer) named sessions with id web.sessions in domain web, owned by team web-analytics, at products/sessions/contract.fluid.yaml. It consumes the page_events output of the product web.page_events_raw (its contract is under products/) and groups each user's events into sessions. Expose one table sessions with session_id string required and unique, user_id string required, started_at timestamp required, ended_at timestamp required and page_count integer required. Run it on Snowflake, writing to the table SESSIONS in schema PUBLIC of database WEB_SILVER, daily at 05:30.
